# Suporte

## Dúvidas sobre um projeto

Use os canais internos definidos no próprio repositório. Não abra issue pública para dados operacionais, credenciais, informações pessoais ou arquitetura restrita.

## Problemas de segurança

Siga a [política de segurança](SECURITY.md). Vulnerabilidades e exposições não devem ser relatadas em issue pública.

## Solicitação de acesso

Informe ao responsável institucional:

- identidade e função;
- repositório necessário;
- finalidade do acesso;
- nível solicitado, leitura, contribuição ou administração;
- prazo, quando o acesso for temporário.

Cada pessoa ou automação deve usar identidade própria. Credenciais não devem ser compartilhadas entre colaboradores.
