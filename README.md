# Perfil da organização EDIACBMSC

Este repositório publica a página institucional e os padrões comunitários da organização GitHub EDIACBMSC.

## Conteúdo

- `profile/README.md`: perfil público da organização.
- `CONTRIBUTING.md`: fluxo comum de contribuição.
- `SECURITY.md`: tratamento de vulnerabilidades e exposições.
- `SUPPORT.md`: orientação de suporte e acesso.
- `PULL_REQUEST_TEMPLATE.md`: verificações mínimas dos Pull Requests.
- `docs/CLASSIFICACAO_INFORMACAO.md`: classes e destinos permitidos.
- `docs/GOVERNANCA_REPOSITORIOS.md`: papel do GitHub e regras dos repositórios.

O GitLab institucional do CBMSC continua sendo a fonte oficial dos projetos corporativos. O GitHub EDIACBMSC é complementar e só recebe publicações expressamente autorizadas.
